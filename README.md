# Rental car

A modern car rental website built with React. Allows users to browse available cars, view details, and interact with a modern, user-friendly interface.

## ✨ Features

- Car catalog — browse and view details of available cars
- Module styling — using **CSS Modules** for maintainable and conflict-free styles
- Interactive UI — smooth navigation and transitions
- State management with **Redux** for dynamic data handling
- API integration via **Axios** for fetching car data
